서비스 소개

시장 데이터를 해석 없이, 있는 그대로

MarketSignal은 한국·미국 경제지표와 국내 상장 종목의 시세·재무·공시를 공개 데이터 그대로 모아 보여주는 무료 정보 사이트입니다. 회원가입이나 로그인 없이 이용할 수 있습니다.

제공하는 것

  • 지표 대시보드 — 코스피·코스닥, S&P500·나스닥, 환율, 금리, 유가 등 주요 지표를 1주~10년 기간으로 겹쳐 보기
  • 종목 차트 — 이동평균선, 볼린저밴드, 일목균형표, RSI, MACD, 박스권 표시와 재무(최근 10년), PER·PBR 밴드, 같은 업종 비교
  • 조건 검색 — 가격·거래·재무 조건을 직접 골라 해당 종목 찾기
  • 공시·일정 — 공급계약·자사주·배당 등 주요 공시, 주총·IR·신규상장·경제지표 일정, 공모주
  • 전체 종목 요약 · 일일 시장 요약

투자 권유가 아닙니다.
이 사이트의 모든 내용은 공개 데이터를 정리해 보여주는 정보 제공용입니다. 특정 종목의 매수·매도를 권유하거나 추천하지 않으며, 조건 검색의 결과도 입력한 조건에 맞는 종목을 나열한 것일 뿐입니다. 투자 판단과 그 결과의 책임은 이용자 본인에게 있습니다.

개인정보 처리방침

시행일: 2026년 10월 6일

1. 수집하는 정보

회원가입이 없으며 이름·전화번호·이메일 등 개인을 알아볼 수 있는 정보를 받지 않습니다.

2. 방문자 수 집계

방문자 수를 세기 위해 접속 IP 주소와 브라우저 정보를 그날만 쓰는 임의값과 섞어 되돌릴 수 없는 값(해시)으로 바꿔 저장합니다. 원래 IP 주소는 저장하지 않으며, 이 값은 2일 뒤 자동으로 삭제됩니다.

3. 서버 접속 기록

데이터를 제공하는 서버(api.marketsignal.kr, stock.marketsignal.kr)는 보안과 장애 대응을 위해 일반적인 웹 서버 접속 기록(IP 주소, 접속 시각, 요청 주소, 브라우저 정보)을 남기며, 14일 뒤 자동으로 삭제됩니다. 사이트 본문은 GitHub Pages로 제공되며, 그 접속 기록은 GitHub의 정책에 따릅니다.

4. 이용자 브라우저에 저장되는 정보

관심종목, 이동평균선 설정, 직접 그린 박스권, 조건 검색 설정, 화면 테마는 이용자 브라우저(localStorage)에만 저장되며 서버로 전송되지 않습니다. 브라우저의 사이트 데이터를 지우면 함께 삭제됩니다.

5. 제3자 제공·광고

수집한 정보를 제3자에게 제공하거나 판매하지 않으며, 광고·추적용 쿠키를 사용하지 않습니다. 차트 라이브러리와 글꼴 일부는 외부 CDN에서 불러옵니다.
